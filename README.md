# HD Externo para Backup Manual

Projeto pessoal de reutilização de hardware, transformando o HD de um notebook antigo em uma unidade externa destinada ao armazenamento e backup de arquivos importantes.

## Objetivo

O objetivo deste projeto foi reaproveitar um HD de notebook que não seria mais utilizado, dando uma nova finalidade ao equipamento como dispositivo de backup externo.

Além de evitar desperdício de hardware, o projeto também teve como foco melhorar a organização e a segurança dos meus arquivos pessoais.

## Materiais Utilizados

* HD de notebook antigo (500 GB)
* Adaptador SATA para USB
* Computador com Linux

## Processo Realizado

1. Realização de backup dos arquivos importantes para a nuvem;
2. Formatação da unidade para remover dados antigos;
3. Configuração do HD para uso como armazenamento externo;
4. Organização da estrutura de pastas;
5. Definição de uma rotina periódica de backup.

## Organização dos Arquivos

Os dados são organizados em categorias para facilitar a localização e manutenção, incluindo:

* Fotos
* Vídeos
* Programas
* Arquivos de segurança
* Documentos
* Outros arquivos pessoais

## Estratégia de Backup

O backup é realizado manualmente em intervalos regulares.

Como grande parte dos arquivos raramente é alterada, normalmente apenas algumas pastas precisam ser atualizadas a cada ciclo de backup.

A revisão periódica permite manter cópias atualizadas dos dados mais importantes sem necessidade de soluções complexas ou automações.

## Armazenamento Físico

A unidade permanece guardada em local seguro quando não está em uso, reduzindo riscos de:

* Danos físicos;
* Quedas;
* Umidade;
* Perda acidental de dados.

## Aprendizados

Durante este projeto pude desenvolver conhecimentos relacionados a:

* Reutilização de hardware;
* Organização de arquivos;
* Boas práticas de backup;
* Preservação de dados pessoais;
* Responsabilidade digital;
* Controle e gestão de informações pessoais.

Mais do que um projeto técnico, esta experiência contribuiu para desenvolver hábitos de organização, valorização dos meus dados e maior responsabilidade no ambiente digital.
